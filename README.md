# 🎬 Clone Disney+

Projeto front-end desenvolvido com foco em **estruturação de layout**, **organização de estilos com SCSS** e **automação de build com Gulp**, inspirado na interface da plataforma Disney+.

---

## 🚀 Tecnologias utilizadas

- HTML5
- SCSS
- JavaScript
- Gulp
- Node.js

---

## 🎯 Objetivo do projeto

Recriar a interface visual do Disney+ para praticar:
- Organização de arquivos front-end
- Pré-processamento de CSS com SCSS
- Automação de tarefas com Gulp
- Build e minificação de arquivos
- Deploy em ambiente de produção

---

## 📋 Funcionalidades

- Layout responsivo
- Estrutura modular de estilos (SCSS)
- Build automatizado com Gulp
- Minificação de arquivos
- Deploy em produção

## ⚙️ Como rodar o projeto localmente

### Pré-requisitos
- Node.js (versão 16 ou superior)
- Git

### Passo a passo

```bash
# Clone o repositório
git clone https://github.com/LucasToretta/clone-disney-plus.git

# Acesse a pasta do projeto
cd clone-disney-plus

# Instale as dependências
npm install

# Execute o Gulp
gulp
